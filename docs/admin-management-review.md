# 后台管理网页优化报告

日期：2026-07-25

范围：`app-config/public/admin`、Pages Functions `admin-api`、`auth-worker` 管理 API 及现有后台测试。

## 一、现状结论

后台已经形成朋友、设备、邀请码、审计日志的基本管理闭环，邀请码明文只在创建响应中返回，列表使用掩码，危险操作有二次确认，Worker 侧也校验了 Cloudflare Access JWT。

当前主要问题集中在四类：

1. 部分状态语义不完整，禁用后的朋友无法重新启用。
2. 时间、健康状态和失败记录的展示存在准确性问题。
3. 页面渲染和数据请求缺少取消、超时、分页及部分失败降级。
4. 玻璃拟态、动态背景和多层滤镜对后台重复操作场景偏重，移动端和辅助功能仍需完善。

截至本轮优化，时间处理、请求生命周期、仪表盘局部失败、朋友列表分页、朋友详情按需查询、无障碍基础语义和移动端侧栏交互已经完成代码级修复。仍需产品确认的只有两项：禁用朋友是否允许恢复，以及是否把后台视觉方向收敛为更系统化、信息密度优先的管理工具。

## 已完成优化

- `formatTime()` 统一处理 Unix 秒/毫秒，修复超过 30 天显示为 1970 年的问题。
- API 请求增加 15 秒超时；页面切换时主动取消在途请求，并保留渲染令牌校验防止旧响应回写。
- 仪表盘统计与审计失败记录使用 `Promise.allSettled` 独立呈现，单项可重试；健康文案限定为 D1/管理服务范围。
- 朋友列表支持服务端搜索、状态筛选和分页；朋友详情改为按 ID 的聚合接口，避免进入详情时拉取整页数据。
- 修复 Toast 动画单位；补充 Toast 状态播报、当前导航、表单标签/错误关联、筛选控件名称和配色按钮展开状态。
- 移动端侧栏增加遮罩、`Escape` 关闭、焦点恢复和 `aria-expanded`；邀请码复制增加传统 `execCommand` fallback。
- `prefers-reduced-motion` 下关闭主内容平滑滚动、背景和节点动画。

## 二、必须修复

### P1：禁用朋友后无法启用

页面文案提示禁用后可以手动启用，但前端没有启用按钮，Worker 也只有 disable 路由。该状态实际成为不可逆操作，属于功能缺口。

涉及：`app-config/public/admin/app.js`、`auth-worker/src/index.ts`、`auth-worker/src/admin/admin.ts`。

处理方式：先确认产品是否允许恢复；若允许，新增幂等的 enable API、审计事件、前端确认流程和测试。

### 已完成：超过 30 天的时间显示错误

`formatTime()` 已将 Unix 秒转换为毫秒，但最终格式化仍使用原始秒值，超过 30 天的时间会被浏览器解释为 1970 年附近的日期。

涉及：`app-config/public/admin/app.js` 的 `formatTime()`。

### 已完成：健康状态文案与实际检查范围不一致

`/admin/health` 当前检查的是 D1 和统计查询，页面却显示“所有服务正常”，并将 TMDB、Trakt、豆瓣代理列为正常状态。这会误导管理员判断线上依赖是否可用。

处理方式：短期改为“管理服务/D1 状态”；长期增加受控的上游探测、响应时间、最近检查时间和超时降级。

### 已完成：路由重复渲染和旧请求回写

`navigate()` 修改 hash 后立即渲染，`hashchange` 事件又会再次渲染。异步请求没有 AbortController 或请求版本校验，快速切换页面时会产生重复请求和旧响应写入已离开页面的 DOM。

## 三、功能完善

- 朋友列表增加服务端搜索、状态筛选和分页，避免一次返回全部朋友。
- 朋友详情增加专用详情接口，避免先拉全量朋友再拉设备。
- 审计日志增加请求 ID、朋友/设备搜索、详情抽屉、自定义日期范围和刷新按钮。
- 审计日志优先改为 `(created_at, id)` 游标分页，避免 OFFSET 分页在新增日志时漏项或重复。
- 对创建朋友、创建邀请码等写操作增加幂等键，避免网络超时重试产生重复数据。
- 增加启用/禁用状态变更的完整审计记录和操作结果刷新。
- 可选增加 CSV 导出、批量撤销设备和批量邀请码管理，但应在单独确认权限和误操作边界后实现。

## 四、UI/UX 优化

建议将后台定位为“系统化、密度适中的管理工具”，保留品牌色和少量层次感，减少大面积动态光晕、噪声纹理和高强度 backdrop-filter。

- 修复 Toast 动画 `250cm` 无效单位，应为 `250ms`。
- 表单标签补充 `for`/`id` 关联、`autocomplete`、错误字段关联和键盘焦点。
- Toast、加载、错误和数据刷新状态增加 `aria-live`。
- 导航增加 `aria-current`，主题/配色按钮增加 `aria-expanded`。
- 移动端侧栏增加遮罩、Escape 关闭和焦点恢复；检查 320px 宽度顶部工具栏。
- 列表筛选条件写入 URL，支持刷新、返回和复制当前视图。
- 邀请码复制增加 Clipboard API 不可用时的自动选中和手动复制 fallback。
- 遵守 `prefers-reduced-motion`，同时关闭平滑滚动和动态背景。

## 五、性能与鲁棒性

- 为所有 API 请求增加超时、取消和统一错误分类。
- 统计、审计、健康状态分开加载，允许局部失败和单项重试。
- 对服务端响应做最小结构校验，避免 malformed response 直接触发 TypeError。
- 使用服务端分页和合适索引；审计查询考虑 `created_at/result/event_type` 组合索引。
- 将 Worker 地址和 Access 登录地址从硬编码改为受控配置，避免环境漂移。
- 为生产后台增加 CSP 和严格的资源来源限制。
- 对玻璃滤镜、噪声 SVG 和动画做低端设备降级，避免滚动和表格交互掉帧。
