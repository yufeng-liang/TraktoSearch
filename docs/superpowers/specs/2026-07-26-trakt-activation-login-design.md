# Trakt 登录页合并激活码设计规格

## 状态

已确认视觉方向：复古票根 v5。

本规格只定义设计和交互，不包含 Android 代码实现。实现前需要先由用户审核本文件。

## 目标

将原独立激活页合并到 Trakt 登录页，让用户在同一个页面完成访问权限激活和 Trakt 登录准备。未激活时，所有可能进入主界面的入口都明确锁定；激活成功后统一恢复可用。

## 页面结构

从上到下：

1. “什么是 Trakt？”说明入口。
2. TraktToSearch 品牌图形和 slogan“从观影清单到网盘资源”。
3. 激活提示文案：“激活后同步你的 Trakt 想看列表”。
4. Haze 毛玻璃激活卡片：标题 `Personal cinema access`、激活码输入框、右侧“激活”按钮、状态提示和“使用 Trakt 登录”按钮。
5. 次级入口：“或从豆瓣导入标记”和“以访客身份进入”。

不再在激活卡片上方放置重复的 Trakt 登录按钮。

## 状态与权限

### 未激活

- 激活码输入框可编辑。
- “激活”按钮可点击；加载时显示进度并防止重复提交。
- “使用 Trakt 登录” disabled。
- “或从豆瓣导入标记” disabled。
- “以访客身份进入” disabled。
- 所有入口使用低对比度禁用样式，并显示“尚未激活”的状态说明。

### 激活成功

- 显示明确的成功状态。
- Trakt 登录、豆瓣导入、访客进入恢复可点击。
- 主界面入口不应在激活成功前通过任何按钮或导航路径进入。

### 激活失败

沿用现有错误分类和国际化资源，至少区分无效、已使用、已撤销、已过期、设备上限、朋友禁用和网络失败；错误文本由 ViewModel 使用英文错误码，UI 使用对应 string resource。

## 视觉方向

- 基础世界：复古影院票根、暖棕纸张、胶卷和入场券。
- 主色：沿用 App 动态壁纸取色机制；复古票根视觉使用暖棕作为原型展示色，不覆盖 Android 动态主题架构。
- 背景元素：爆米花、票根、胶卷、场记板、摄影机、星光和胶片底边纹理；透明度受控，不影响文字和输入区域。
- 激活卡片：使用 Haze 毛玻璃效果，包含半透明表面、背景模糊、轻微顶部高光、细边框和柔和阴影。
- 可访问性：禁用态必须有足够的明度层级；不能只依赖颜色表达状态；焦点态和错误态需要清晰可见。

## 键盘与窗口行为

- 激活码输入框获得焦点、键盘出现时，底部激活卡片随 IME 上移。
- 键盘收起后恢复原位。
- Compose 实现使用 `imePadding()` 和 `navigationBarsPadding()`；小屏幕或错误文案变长时配合可滚动容器，避免输入框、错误文案和按钮被键盘遮挡。
- 页面需要保持 edge-to-edge 和现有系统栏策略，不通过固定屏幕高度定位卡片。

## 主题取色

- Android 12/API 31 及以上：默认使用系统动态壁纸取色。
- 用户设置自定义 accent 时，使用现有自定义 Monet 色板。
- Android 11/API 30 及以下：使用现有固定浅色/深色配色。
- 复古票根的暖棕色作为组件材质和插画元素的设计参考，不应破坏用户选择的主题色。

## 实现边界

- 复用现有 `AuthViewModel` 激活协议、错误映射和 `LoginScreen` Trakt OAuth 流程。
- 修改 `ActivationLoginScreen`/登录导航状态和相关 Compose UI，删除旧的独立 `AuthScreen`，不修改网关 API 协议。
- 同步更新 values、values-zh、values-ja、values-ko 的用户可见文案资源。
- 不在源码、BuildConfig、APK 或 Pages 文件中加入任何密钥。

## 验收标准

- 冷启动未激活时只能看到登录页，四个入口均按状态正确禁用。
- 输入激活码时键盘出现，激活卡片上移；键盘收起后恢复。
- 激活成功后所有入口恢复可用，且不会短暂进入主界面后又回到激活页。
- 激活错误按现有错误类型显示对应本地化文案。
- Android 12+ 动态取色、自定义 accent、浅色/深色模式均保持可读性。
- 完成 `git diff --check`、相关单元测试和 debug 构建；真实设备上补充键盘、点击和截图证据。
