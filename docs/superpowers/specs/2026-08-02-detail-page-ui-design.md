# 详情页 UI 优化设计

## 目标

改善详情页顶部操作区、简介可发现性和季信息卡片的视觉层级，同时保持现有详情页的拟态玻璃主题、导航和数据行为不变。

## 交互设计

- 豆瓣同步重试按钮复用详情页的拟态玻璃圆形图标按钮。同步中显示进度指示器，并保持按钮不可点击。
- 简介标题不再显示冒号。
- 简介超过三行时默认显示三行，第三行末尾显示主题色「查看全部」。整个简介区域可点击展开。
- 展开后显示全文，文本末尾显示主题色「收起」。再次点击整个简介区域收起。
- 三行以内的简介不显示展开提示，也不产生无意义的点击行为。

## 视觉设计

- 重试按钮与返回、分享按钮共享 `NeumorphicIconButton` 的玻璃、高光、边框和阴影参数。
- 季信息卡片保留当前圆角、内容和展开动画，只增加主题边框与低强度拟态外阴影，区分卡片和沉浸式背景。

## 实现边界

- 扩展共享拟态图标按钮的禁用能力，默认参数保持现有调用方行为不变。
- 在简介组件内部测量折叠文本，确保「查看全部」出现在第三行末尾，不依赖系统省略号偶然可见。
- 新增英、中、日、韩四种语言的简介操作文案。
- 不改动详情数据模型、网络请求、季集展开状态和资源加载流程。

## 验证

- Compose 测试覆盖简介短文本、长文本折叠提示和展开/收起交互。
- 共享按钮测试覆盖禁用状态不触发点击。
- 运行详情相关测试和 `assembleDebug`，安装到已连接设备后验证详情页截图及崩溃日志。
