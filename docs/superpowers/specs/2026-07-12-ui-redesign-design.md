# UI 重设计规格 — 影院沉浸暗色风

> 分支：`ui-redesign-experimental`  
> 日期：2026-07-12  
> 方向：A 方案 — 影院沉浸暗色风

---

## 1. 设计目标

在保留现有功能的前提下，为影视搜索/标记 App 打造一套更具影视氛围、现代感和沉浸感的 UI：

- **沉浸感**：让海报、剧照成为视觉主角，减少生硬分割线与卡片边框。
- **毛玻璃与层级**：利用 Haze 模糊、渐变遮罩、半透明浮层营造空间感。
- **多彩但不杂乱**：主题强调色跟随设置里的「应用色调」（壁纸取色或预设莫奈色），评分、网盘标签等使用固定功能色。
- **现代动画**：共享元素转场、列表 stagger 入场、按钮按压反馈。

---

## 2. 全局设计系统

### 2.1 色彩

| 用途 | 色值 | 说明 |
|------|------|------|
| background | `#0F0F1A` | 页面底层背景，影院暗场感 |
| surface | `#1A1A2E` | 卡片、浮层底色 |
| surfaceVariant | `#242442` | 对话框、底部 sheet 底色 |
| primary | 跟随设置「应用色调」 | 想看/已看按钮、选中态、开关 |
| onPrimary | `#FFFFFF` | 主色上的文字/图标 |
| 评分 | `#F4A460` | 琥珀/金色，高分更亮 |
| 网盘标签 | 品牌色 15% 透明底 + 品牌色文字 | 夸克蓝、百度蓝、阿里靛、迅雷蓝、UC 橙、115 蓝 |
| 年份标签 | 黑色 50% 透明底 + 白色文字 | 毛玻璃底 |

动态取色：详情页/演员页根据海报/头像主色生成顶部渐变 overlay（透明度 50%-0%）。

### 2.2 材质与层级

- **底部导航**：悬浮胶囊，背景 `rgba(255,255,255,0.08)`，Haze blur 20px，边框 `rgba(255,255,255,0.1)`。
- **顶部工具栏**：返回/分享按钮用毛玻璃圆形浮层，blur 10px。
- **卡片浮层**：半透明 surface + 轻阴影，减少实线边框。
- **搜索栏**：毛玻璃胶囊，blur 12px。

### 2.3 字体

- 页面大标题：28sp Bold，白色
- 分类标题：18sp SemiBold，白色 90%
- 正文：14sp Regular，白色 65%
- 辅助标签：11sp Medium，白色 50%，大写
- 详情页片名：32sp ExtraBold

### 2.4 圆角与间距

- 大卡片/分组：20dp
- 海报卡片：14dp
- 按钮/Chip：18-20dp
- 底部导航：32dp 顶部圆角
- 页面水平内边距：16dp

### 2.5 动画

- 列表入场：stagger 30ms，从下方 20dp 滑入 + alpha 0→1
- 按钮按压：scale 0.96 + 背景亮度变化
- 海报按压：scale 0.97
- 页面切换：共享元素转场（沿用现有开关）+ 250ms 淡入淡出

## 3. 分页面设计

### 3.1 搜索页

- 顶部标题区：「搜索」28sp Bold + 副标题「发现你的下一部观影」13sp 50%白。
- 搜索栏：毛玻璃胶囊，内嵌电影/电视剧下拉切换。
- 热门搜索：暗色半透明 chip，圆角 18dp，hover 时亮度微增。
- 底部导航：悬浮毛玻璃胶囊，选中项用应用色调。

### 3.2 发现页

- 顶部分类：横向滑动 Hero 卡片（口碑榜/Top250/正在热映），大幅渐变卡片。
- 每个分类标题：左标题 16sp SemiBold + 右「查看全部(数量) ›」12sp 50%白。
- 海报列表：横向滚动，海报右上角显示评分，高分金色、低分灰色。
- 海报下方：片名 12sp SemiBold，单行截断。

### 3.3 想看/已看列表

- 顶部：毛玻璃搜索栏 + 筛选图标。
- 想看/已看：大圆角胶囊按钮，选中态应用色调。
- 电影/电视剧 Tab：下划线高亮。
- 网格：3 列 poster，左下角年份标签，片名 11sp SemiBold，类型标签金色。

### 3.4 影视详情页

- 顶部：海报主色渐变背景，高度 260dp；返回/分享按钮为毛玻璃圆形浮层。
- 海报与信息：海报 100×150dp 大卡片 + 片名/原名/年份/类型/评分/时长在同一层级。
- 操作按钮：想看/已看/评分三等分大按钮，选中态应用色调 + 发光阴影。
- 演职员：圆形头像横向滚动，名字 10sp 截断。
- 简介：16sp 标题 + 13sp 正文 65%白，行高 1.6。
- 资源/评论/推荐 Tab：吸顶 Sticky Tab，毛玻璃 segmented control。

### 3.5 演员详情页

- 顶部：头像取色渐变背景，高度 200dp。
- 头像 90×120dp 大卡片 + 姓名/英文名/职业/出生日期。
- 简介：放在半透明圆角卡片内。
- 图片/参演电影：横向滚动，与详情页风格一致。
- 外部链接（Wikipedia/X）：小图标按钮置于头像下方。

### 3.6 设置页

- 分组标题：12sp 大写，40%白。
- 分组卡片：20dp 圆角，半透明 surface，内部 1dp 分隔线。
- 统计入口：独立大卡片，图标在主题色 15% 底色的圆角方块中。
- 开关：统一应用色调。
- 图标风格：emoji/线性图标 + 主题色浅色背景方块。

### 3.7 筛选页

- 顶部：返回 + 标题 + 重置。
- 电影/电视剧 Tab：下划线高亮。
- 筛选条件 chip：半透明毛玻璃，圆角 18dp。
- 结果列表：海报左 + 信息右，评分金色。

## 4. 组件规范

### 4.1 底部导航

```
悬浮胶囊
- 背景：rgba(255,255,255,0.08)
- backdropFilter: blur(20px)
- 边框：1px rgba(255,255,255,0.1)
- 圆角：顶部 32dp
- 图标+文字垂直排列
- 选中项：应用色调
```

### 4.2 评分标签

```
高分（>=8.0）：#F4A460 背景 90% 不透明度 + 黑色文字
中分（6.0-7.9）：#F4A460 背景 70% 不透明度 + 黑色文字
低分（<6.0）：灰色背景 + 白色文字
位置：海报右上角
```

### 4.3 操作按钮组

```
三等分大按钮
- 未选中：rgba(255,255,255,0.08) + blur(8px)
- 选中：应用色调 + 发光阴影 (0 4dp 20dp primary@30%)
- 圆角：14dp
- 图标在上，文字在下
```

---

## 5. 技术要点

- 主题强调色跟随 `MonetAccent` 设置，不再固定 Trakt 红。
- Haze 模糊使用已引入的 `dev.chrisbanes.haze` 库。
- 动态取色依赖 `palette` 或 Coil 的 palette 扩展（需评估是否新增依赖）。
- 暗色主题为默认/推荐，浅色主题仍需兼容但非本次重点。
- 所有 UI 文字继续走 stringResource，新增文案需同步 4 语言。

---

## 6. 不在本次范围

- 不改动业务逻辑、数据结构、API 调用。
- 不新增大型动画库（如 Lottie）。
- 不重绘所有图标，优先使用现有 Material Icons 或 emoji 占位后替换。
- 浅色主题不做额外重设计，沿用 Material3 动态/静态配色。

---

## 7. 验收标准

- [ ] 6 个核心页面视觉风格统一，暗色沉浸感明显。
- [ ] Haze 毛玻璃在底部导航、顶部按钮、搜索栏、详情页浮层生效。
- [ ] 主题强调色正确跟随设置里的应用色调。
- [ ] 列表有 stagger 入场动画，按钮有按压反馈。
- [ ] Debug 构建可正常运行，无编译错误。
