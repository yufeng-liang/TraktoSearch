# TrackToSearch 页面背景风格预览 V2 设计

## 背景

上一版预览使用了通用的电影工具布局，和实际 App 截图的页面骨架、内容密度、玻璃组件比例及光晕位置不一致。本版以用户提供的 Search、Discover、Mine、Settings 四张浅色截图为视觉基准，只比较背景风格，不重新设计页面。

## 设计目标

- 使用接近真实 Android 截图的 390 x 844 手机画布。
- 保留四个页面的实际结构：搜索胶囊与搜索词、发现榜单与海报横向列表、我的三列海报网格、设置分组卡片与外观四宫格。
- 保持前景材质统一：半透明白色玻璃、细白边、柔和外阴影、轻微内高光、日式桥绿强调色。
- 只切换页面背景：截图基准、单块蓝紫弥散、低饱和 Mesh、柔和 Aurora。
- 通过页面切换检查同一背景在不同内容密度下的可读性。

## 方案选择

1. **截图作为背景**：最贴近真实，但无法独立替换背景，不能回答本次比较问题。
2. **通用卡片重绘**：实现简单，但会重复上一版与真实 App 脱节的问题。
3. **真实页面骨架 + 独立 CSS 背景层**：页面结构贴近截图，背景可独立切换，适合本次目标，选用此方案。

## 交互与边界

- 顶部仅提供背景风格与页面切换；不加入深色模式、业务筛选或数据操作，避免引入截图中不存在的状态。
- 底部导航和页面顶部控件可点击，用于切换模拟页面。
- 海报使用本地 CSS 色块模拟图像占位，不把网络图片加载失败误认为背景效果问题。
- 预览不修改 Android Compose 源码，不改变生产背景实现。

## 验收标准

- 四个页面的标题、主要内容层级、底部导航和卡片位置与截图相近。
- 四种背景在同一页面内容下可切换，且前景卡片材质不随风格改变。
- 390px 左右窄屏无页面级横向溢出；发现页和海报列表只在内容区域保留截图中的横向露边效果。
- HTML 通过 HTTP 返回并包含四个页面、四种背景、页面切换脚本；`git diff --check` 无错误。
