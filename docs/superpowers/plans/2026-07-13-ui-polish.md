**目标：** 基于用户反馈修复搜索页、底部导航、影视卡片、发现页 Sheet、设置页标题栏、详情页沉浸渐变等 9 类 UI 细节问题。

**技术栈：** Android Jetpack Compose, Material3, Haze

  当前 `TmdbAllSheet` 调用处（`DiscoverScreen` 的 `tmdb-popular` 分支）传入的 title 是 `stringResource(R.string.discover_popular)`。改为传入 `stringResource(R.string.discover_trending)`。

- [ ] **步骤 2：为 TmdbAllSheet 增加 timeWindow 切换胶囊**

  在 `TmdbAllSheet` 的顶部 Row 中，关闭按钮左侧增加一个 `SingleChoiceSegmentedButtonRow`：
  ```kotlin
  val options = listOf("day" to R.string.tmdb_today, "week" to R.string.tmdb_week)
  SingleChoiceSegmentedButtonRow {
      options.forEachIndexed { index, (value, labelRes) ->
          SegmentedButton(
              shape = SegmentedButtonDefaults.itemShape(index = index, count = options.size),
              onClick = { onTimeWindowChange(value) },
              selected = selectedTimeWindow == value
          ) {
              Text(stringResource(labelRes))
          }
      }
  }
  ```

- [ ] **步骤 3：扩展 TmdbAllSheet 签名**

  ```kotlin
  internal fun TmdbAllSheet(
      title: String,
      selectedTimeWindow: String,
      onTimeWindowChange: (String) -> Unit,
      ...
  )
  ```

- [ ] **步骤 4：在 DiscoverScreen 中维护 Sheet 的时间窗口状态**

  `DiscoverScreen` 已有一个 `selectedTimeWindow` State。在调用 `TmdbAllSheet` 时传入当前 `selectedTimeWindow`，并在 `onTimeWindowChange` 中同步修改该 State 以触发 ViewModel 重新加载列表：
  ```kotlin
  TmdbAllSheet(
      title = stringResource(R.string.discover_trending),
      selectedTimeWindow = selectedTimeWindow,
      onTimeWindowChange = {
          selectedTimeWindow = it
          viewModel.loadTmdbTrending(it)
      },
      ...
  )
  ```
