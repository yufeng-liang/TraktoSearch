- 采用 MVVM 架构与 Clean Architecture 分层：UI 层（ui/screen）通过 Hilt 注入 ViewModel，业务逻辑层（data/repository）协调多个远程 API 服务。
- 依赖注入使用 Hilt (dagger-hilt)，网络请求基于 Retrofit + OkHttp，本地持久化结合 Room 数据库与 DataStore。
- 导航系统基于 Jetpack Navigation Compose，支持共享元素过渡动画（SharedTransitionLayout）。
- 模块化设计：di 包集中管理网络客户端与 Repository 实例；data/remote 按 API 提供商分包（trakt, tmdb, douban 等）。
